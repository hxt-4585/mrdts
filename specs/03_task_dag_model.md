# 03 DAG 任务参数

## 1. DAG 拓扑参数

| 参数名         |                      符号 | 默认值 | 说明                             |
| -------------- | ------------------------: | -----: | -------------------------------- |
| DAG 节点数     |        $N_{\mathrm{dag}}$ |     10 | 每个 DAG 包含的子任务数量        |
| 最大出度       | $d_{\mathrm{out}}^{\max}$ |      2 | 单个子任务最多依赖的后继任务数量 |
| DAG 稠密度参数 |                    $\rho$ |    1.0 | 控制 DAG 中依赖边的生成密度      |
| DAG 随机性参数 |                  $\delta$ |    0.5 | 控制 DAG 拓扑结构的随机程度      |

## 2. 子任务参数

对于任意子任务 $i$，定义其计算量、输入数据量和中间结果数据量。

| 参数名                 |                    符号 |      默认取值 | 单位       | 说明                                     |
| ---------------------- | ----------------------: | ------------: | ---------- | ---------------------------------------- |
| 子任务计算量           |                   $c_i$ | $[10^7,10^8]$ | CPU cycles | 完成该子任务所需的计算周期数             |
| 子任务输入数据量       |     $d_i^{\mathrm{in}}$ |   $[100,500]$ | KB         | 原始任务输入数据量                       |
| 前驱任务中间结果数据量 | $d_{ji}^{\mathrm{mid}}$ |   $[100,300]$ | KB         | 前驱子任务 $j$ 传递给子任务 $i$ 的数据量 |
