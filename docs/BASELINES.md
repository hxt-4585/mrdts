# 基线方法与历史效果

记录日期：2026-11-06。本文保留基线的设计与实验结论，供后续 Codex 接手；即使部分代码、结果或聊天记录被删除，也不要把“文件不存在”理解为“从未实现”。以下数字来自保存的历史实验，未重新训练或评估。根 README 和 PROJECT_STRUCTURE 中“没有训练入口、奖励未实现”的旧描述已过时。

## 共通设计

Master 高层负责 Member UAV 的二维飞行动作，Member 低层负责 DAG 子任务的执行位置（同区域 Member、BS 或用户本地设备）。子任务顺序基本采用 ERS，不由 PPO 学习排序。

冻结低层 PPO 的高层奖励为负的归一化系统平均 DAG 时延，另扣越界惩罚；低层使用子任务等待、传输、排队和计算时间构成的归一化时延奖励。

冻结低层的高层对照方法默认使用 random_uav_ppo 的第 371 轮低层权重，冻结后采用合法动作掩码下的 argmax；环境配置从低层检查点恢复。它们用于固定调度能力后比较高层方法。

## 方法与实现

方法入口为 `methods/<名称>/run.py`，配置为 `config/methods/<名称>.toml`。

| 名称 | 是什么、如何实现 |
|---|---|
| random | 无训练的随机对照。每时隙随机采样 UAV 飞行动作，ERS 排序后，在合法执行节点中随机放置子任务。 |
| random_uav_ppo | 随机飞行下只训练低层。无 Master 网络；每架 UAV 默认每 10 时隙重新采样二维动作，中间保持向量，外边界处反向。每架 Member 独立 PPO，是其他高层基线的低层预训练来源。 |
| frozen_member_ppo | 冻结 Member，只用 PPO 学习 Master 的逐时隙飞行动作。保留共享 Actor、集中式 Critic，跨时隙计算 GAE；低层不更新。 |
| centralized_cem | 集中式静态部署搜索。CEM 对所有 UAV 的归一化目标位置采样，仿真评价平均时延，选择精英并更新分布；用独立验证任务流选择部署。UAV 从初始位置按速度限制飞向目标，到达后保持。 |

静态部署方法不能直接等同于动态飞行策略。

## 已保存的效果

以下是不同实验条件下的记录，不能跨行直接排名。时延单位为秒，失败率沿用历史输出的 `failed_dags / dag_count`，不应解释为统一的超时率。

| 方法 | 历史结果与结论 |
|---|---|
| random | 早期 seed=45、500 时隙、50,000 DAG 的记录：平均时延 2.4999，失败率 88.52%。负载与后续 30 用户实验不同，只保留为早期随机参考。 |
| random_uav_ppo | 保存了完成 371 轮的低层检查点，之后训练被中断。训练第 1 轮时延 0.5585、失败率 5.48%，第 371 轮为 0.4013、0.193%。不同轮的任务与随机轨迹不同，这只是训练记录；本次未找到独立留出评估汇总，不能据此量化泛化收益。 |
| frozen_member_ppo | 历史训练被中断；最后完整记录为第 411 轮，时延 0.4509、失败率 2.60%、越界 374 次。首轮时延为 0.3436。不能据此声称训练已稳定改善，本次未找到独立留出评估汇总。 |
| centralized_cem | 60 代完成后的 10 个留出回合，每回合 500 时隙：时延 0.217345、失败率 0%；同组悬停 0.364392，随机飞行 0.382600，时延分别降低约 40.35% 和 43.19%。续训至 100 代后暂停，最佳验证时延 0.215301；没有该次续训的最终测试汇总。 |
